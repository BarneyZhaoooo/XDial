# iOS 自动场景列表收起验收

2026-11-16，基于 `origin/main` 的 `d50a937`，独立工作树验证。

## 行为

自动模式默认仅显示当前选择、网络判断摘要和展开入口。展开不会改变自动开关；
关闭自动或手动选择另一个场景后显示完整列表，重新开启自动立即收起。
连接状态仍由拨盘区域表达；场景被选中不表示已经连接。

## 验证结果

- Debug iOS Simulator 构建成功；使用正常模拟器 ad-hoc 签名安装，插件校验整包 `matchesLocal=true`。
- 使用仓库公开 `ios/Examples/Seed.example.json` 注入本地预览包；未使用企业私有配置。
- 设备：iPhone Air / iOS 27.0，插件 UDID `CBED59E7-F6C7-4BDA-9CF2-36E17B0F0FE5`。
- 首次进入自动模式：四张详细场景卡隐藏；摘要显示当前选择和出口地区；未登录提示与登录按钮可见。
- 点展开入口并滚动：四场景可见，自动开关仍开启，入口变为「收起场景」。
- 手动选择「在公司」：自动关闭，完整列表保留，拨盘状态仍为「未连接」。
- 点拨盘：观察到「正在连接…」与「取消连接」，随后「已连接」；断开后恢复「未连接」。
- 重新开启自动：恢复地区对应场景，列表收起，独立显示登录状态。
- 用现有 `-XDialPreviewError` 注入连接超时：错误卡 `home-problem` 仍在场景区之前，列表保持收起。
- 浅色与深色截图检查通过。
- `git diff --check`、`make public-content-gate` 通过。后者启动时提示当前 shell 找不到 Go，但公开内容检查脚本本身成功退出。

这里只验收界面与 FakeTunnel 状态转换，不代表真机 VPN 数据面或物理震动验收。
拨盘旋转、触感、自动判断和分流实现未修改；没有运行完整 XCTest 回归。

## 构建说明

环境没有可执行的 `xcodegen`，本次复制同一 main 工作树已有的生成工程到独立工作树，
源文件列表未变化。Libbox 使用同一 main 已构建的 framework 副本；构建产物和示例注入目录都在
忽略的 `build/` 下。最初禁用签名的包发生钥匙串配置错误，改用模拟器 ad-hoc 签名后恢复正常。

本任务只安装模拟器 Debug；未覆盖 macOS Debug，未合并、推送或发布 TestFlight。
